# Limitations

This is unexecuted source construction. No dependency installation, typecheck, lint, tests, browser session, generator, external recorder or experiment has run. A static review is not evidence of cryptographic correctness or privacy.

Only the closed IOS-style IPv4 grammar in GRAMMAR is supported. Unknown lines pass through unchanged, including in naive-mask, and can retain identifiers. Forwarding-affecting unknown lines make utility unsupported. Naive-mask collapses names to MASKED; multi-node flow utility is zero by construction under ambiguity rules, not a measured result.

Crypto-PAn preserves prefixes and reveals structure. Keys are synthetic experiment material or fresh worker-local session material; none makes a real configuration safe to share. Public-pattern detection misses split/embedded identifiers and unknown formats. Generic scrubbing can destroy benign text. ASN substitutions deliberately leave out-of-range values unchanged with a diagnostic. Reserved, multicast, network and broadcast outputs are named failures, never reasons to choose a more favorable key.

The deterministic evaluator is builder-written and may be wrong. It models connected/static/local routing only; BGP is metadata, not learned routing. Batfish and independent author agreement remain pending. Missing or tampered recordings are not_run, not successful anonymisation. Unsupported traces never earn preservation credit.

Decoys are builder-generated while held-out cases will be independently handwritten, which can make fingerprint matching easier. Probe A's prefix inference applies only to a prefix-preserving threat model; it must not be interpreted as evidence for unrelated transforms. Bootstrap uncertainty does not account for generator bias or transfer to real networks. No winner or combined privacy/utility score is defined.

The local preview uses smoke fixtures, not scored data. Paste mode offers public-pattern heuristics only and deliberately has no oracle or rate. Everything is transient; closing the tab or cancelling discards the worker. Aggregate exports exclude configurations, filenames, leaked strings, keys and correspondence maps. No output is certified safe to share.

Retention metrics align stable file IDs and line ordinals, then credit a labelled span only when its characters map contiguously and uniquely across all optimal character-edit alignments. Earlier replacement length changes can shift a retained span; repeated-token ambiguity counts as changed. Lines exceeding two million alignment cells conservatively count changed to bound worker memory. Line deletion/reordering and ambiguous edits can overstate redaction. Batfish full-trace comparisons require validated native trace adaptation into stable IDs; unfamiliar shapes remain not_run, not evaluator-generated oracle answers.
